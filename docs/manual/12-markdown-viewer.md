# 12. Markdownビューア（`:view` / `:mark`）

`.md`/`.markdown`ファイルを開いた直後は、他のファイルと同じように**そのままの生ソース**が表示され、通常どおり編集できます。見出し・リストなどの構造を見やすく表示したい場合のみ、コマンドで明示的に切り替えます。

## `:view` — 閲覧ビューへ切り替える

現在のバッファが`.md`/`.markdown`ファイルの場合のみ、COMMANDモードで`:view`と入力すると、Markdown記法を取り除いて読みやすく整形した**読み取り専用の閲覧ビュー**に切り替わります。

- 見出し（`#`〜`######`）: レベル1・2はタイトル行の下に`=`/`-`の下線を引きます。レベル3〜6は元の`#`接頭辞を保持します。
- 箇条書き（`-`/`*`/`+`）は`- `に統一されます。タスクリスト（`- [ ]`/`- [x]`）はチェックボックス表示になります。
- 番号リスト（`1.`）はそのまま表示され、内容だけがインライン記法変換の対象になります。
- 引用（`>`）は`| `（ネストは階層分繰り返し）に変換されます。
- 水平線（`---`/`***`/`___`）は横幅いっぱいの`-`の並びになります。
- コードブロック（`` ``` ``/`~~~`）は4スペースインデントで表示され、中の**太字・斜体等は変換されません**。
- 太字（`**text**`）・斜体（`*text*`）・インラインコード（`` `code` ``）の記号は取り除かれます。
- リンク（`[text](url)`）は`text (url)`、画像（`![alt](url)`）は`[image: alt] (url)`と表示されます。

このエディタの本文描画は等幅フォントのグリッド描画のため、色分けやフォントの太字化はできません。閲覧ビューは記号を整理して構造を読みやすくするものであり、色付きレンダリングは行いません。

## `:mark` — ソース表示へ戻る

`:view`で開いた閲覧ビュー中に`:mark`と入力すると、元のMarkdownソース・ファイルパス・カーソル位置がそのまま復元されます。

## 保存について

閲覧ビュー表示中は読み取り専用として扱われ、`:w`は「保存先がありません」というエラーになります（実ファイルがレンダリング後のテキストで上書きされてしまう事故を防ぐためです）。ソースに戻ってから`:w`で保存してください。

## 注意点

- `:view`は`.md`/`.markdown`ファイル以外では`E: not a markdown (.md) file`というエラーになります。
- `:view`で閲覧ビューを開いたまま`:e`や検索結果ジャンプなどで別のファイルへ切り替えた場合、その後の`:mark`は無効化され`E: not in markdown view`になります（切り替え前のファイルへは通常のバッファ切り替え操作で戻ってください）。
- `:split`/`:vsplit`で同じファイルを複数ペインに開いている場合でも、片方のペインだけ`:view`しても他のペインの編集内容は失われません。`:mark`で戻ると再び同じ内容を共有する状態に復帰します。
